- The Paper design remains the source of truth for the homepage UI during this refactor.
- Use Paper MCP to inspect the Paper design file and artboards.
- Do not use Playwright or the paper.design web app as the primary design-reference path.
- Use browser tooling only for verifying the implemented local site.
- Target shared editorial or marketing pages only in this run. Do not generalize internal app flows.
- Move homepage composition into `src/pages/index.astro`. Do not preserve `LandingPage.astro` if it only recreates page structure.
- Build a shared editorial design system with compound primitives, shared tokens, and one uniform block system using typed block kinds.
